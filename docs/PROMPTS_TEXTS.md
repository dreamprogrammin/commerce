# Промпты для текстов: товары, разделы, бренды

Готовые промпты для ChatGPT / Claude / любой нейросети. Составлены 14 октября 2026
по тому, что уже стоит на сайте: поля базы, формат HTML с иконками, правила длины
из кода (`utils/seoTitle.ts`, `utils/seoDescription.ts`) и запреты, которые
проверяют стражи сайта (`check-section-texts.mjs`, `check-product-titles.mjs`).

**Как пользоваться.** В новый чат вставить сначала «Общие правила», потом нужный
промпт и заполнить в нём блок «ДАННЫЕ». Ответ раскладывается по полям админки
один к одному. Перед сохранением — проверить цифры глазами: нейросеть может
ошибиться даже с запретом выдумывать.

**Главное — давать факты.** Чем больше фактов в «ДАННЫХ» (с коробки, из
инструкции, с сайта производителя), тем лучше текст. Без фактов промпт велит
писать коротко, а не сочинять.

## Общие правила (вставлять первым во всех случаях)

```
Ты пишешь тексты для интернет-магазина детских игрушек «Ухтышка» (uhti.kz, Алматы, Казахстан). Пишешь по-русски, для родителей, которые выбирают игрушку ребёнку. Тон — спокойный, конкретный, без рекламного крика.

ГЛАВНОЕ ПРАВИЛО: никаких выдуманных фактов. Используй только то, что дано в блоке ДАННЫЕ и в фактах о магазине ниже. Если не указаны размер, материал, страна, батарейки, сертификаты, возраст, год основания бренда, награды — не пиши о них вовсе. Короче, но верно — лучше, чем красиво и неверно.

ЗАПРЕЩЕНО:
- эмодзи и символы-украшения в тексте;
- «широкий выбор», «большой/огромный/богатый выбор», «широкий ассортимент», «вы найдёте», «в нашем каталоге», «в нашем интернет-магазине», «заказывайте прямо сейчас», «прямо сейчас»;
- «официальный дилер», «эксклюзивный представитель», «гарантия производителя», «сертифицировано», «оригинал» — если этого нет в ДАННЫХ;
- слова целиком ЗАГЛАВНЫМИ, больше одного восклицательного знака на текст;
- обещать доставку по всему Казахстану за 1–3 дня или «за 1 день».

ФАКТЫ О МАГАЗИНЕ (можно использовать, менять нельзя):
- Магазин «Ухтышка», сайт uhti.kz, свой склад в Алматы (мкр. Шапагат).
- Доставка по Алматы — 1–3 рабочих дня, курьер 1 000 ₸, от 15 000 ₸ — бесплатно.
- Доставка по Казахстану — 3–7 рабочих дней, стоимость зависит от адреса и веса.
- Самовывоз бесплатно: г. Алматы, мкр. Шапагат, ул. Амангельды, 100, ежедневно 9:00–22:00.
- Оплата: наличными при получении (Алматы), переводом или по QR через Kaspi.
- Бонусы за каждую покупку: 1 бонус = 1 ₸ скидки на следующий заказ, активируются через 14 дней.

ФОРМАТ БОЛЬШИХ ТЕКСТОВ — HTML ровно в таком виде (так рисует сайт):
<h2 data-icon="fluent-emoji-flat:ИКОНКА">Заголовок</h2>
<p>Абзац.</p>
<h3 data-icon="fluent-emoji-flat:ИКОНКА">Подзаголовок</h3>
<ul>
  <li data-icon="fluent-emoji-flat:ИКОНКА">Пункт</li>
</ul>
Только теги h2, h3, p, ul, li. Без <br>, <strong>, ссылок, стилей и классов.
Иконки — только из этого списка, по смыслу: racing-car, teddy-bear, doll, baby, child, puzzle-piece, brain, rocket, robot, house, sparkles, star, wrapped-gift, trophy, light-bulb, check-mark-button, delivery-truck, artist-palette, musical-notes, building-construction, bulldozer, superhero, princess, mermaid, rainbow, gem-stone, battery, speaking-head, direct-hit, party-popper.

Отвечай строго по полям, которые перечислены в задании, — каждое поле с новой строки в виде «ИМЯ_ПОЛЯ:», дальше значение. Без пояснений до и после.
```

## 1. Карточка товара

Поля в базе: `name` (название), `description` (текст на странице), `seo_description`
(описание для выдачи Google). Заголовок страницы (`title`) сайт собирает сам из
названия — `meta_title` и `seo_title` оставлять пустыми.

```
ЗАДАНИЕ: тексты для карточки товара.

ДАННЫЕ:
- Что за товар (тип): 
- Бренд: 
- Серия/линейка (если есть): 
- Код модели (артикул с коробки): 
- Название с коробки / от поставщика: 
- Характеристики (размер, материал, батарейки, аккумулятор, число деталей, режимы, звук/свет, управление): 
- Возраст с коробки: 
- Комплектация (что в коробке): 
- Цвет: 
- Цена (₸): 
- Особенности, которые видно на фото: 

ПОЛЯ:

name: название товара. Схема: «Тип + бренд/серия + модель и код — 3–5 главных характеристик через запятую». Часть ДО длинного тире « — » не длиннее 60 знаков и обязана целиком содержать тип, бренд и код модели — Google показывает в заголовке именно её. Код модели писать как на коробке (BG1544, 60411, T904A). Пример: «Робот-собака S-Cyber Dog BG1544 SuboTech — 24,5 см, Bluetooth, голосовые команды на русском, ИК-пульт, Li-Ion аккумулятор».

description: HTML по формату из правил:
  1) <h2> — название товара и главная польза одной фразой;
  2) <p> 500–900 знаков: что это, как играют, размеры, питание, управление — только из ДАННЫХ; если батарейки не входят в комплект — сказать прямо;
  3) <h3> «Почему выбирают …» и <ul> из 4–6 пунктов, каждый — конкретный факт (не «высокое качество»);
  4) если дана комплектация — <h3> «Что в коробке» и <ul> по пунктам.

seo_description: 120–160 знаков, без HTML. Вперёд — тип, модель и 2–3 главные характеристики, дальше «Купить в Ухтышке с доставкой по Казахстану» и возраст, если он дан.
```

## 2. Раздел каталога

Поля в базе (`categories`): `seo_h1`, `seo_title`, `meta_description`, `seo_text`,
`seo_keywords`. Число моделей и цена «от» в описание для выдачи сайт дописывает
сам — их в `meta_description` не ставить. Корневым разделам («Мальчикам»,
«Девочкам», «Малышам», «Конструкторы», «Творчество», «Игры», «Отдых») текст
задан в коде сайта (`constants/categoryStaticText.ts`) — для них промпт не нужен.

```
ЗАДАНИЕ: тексты для раздела каталога.

ДАННЫЕ:
- Название раздела: 
- Родительский раздел: 
- Какие товары в разделе сейчас (типы, бренды, примеры моделей): 
- Возраст, для которого товары: 
- Как люди ищут (запросы, другие названия — «толокар», «толкалка»): 
- Подразделы (если есть): 

ПОЛЯ:

seo_h1: заголовок на странице, 2–5 слов: тип товара и для кого («Толокары для детей»). Без «купить», без города.

seo_title: заголовок для выдачи Google, вместе с хвостом « | Ухтышка» не длиннее 60 знаков. Главный запрос в начале, затем уточнение и «в Алматы». Пример: «Толокар для детей — машинки-толокары в Алматы | Ухтышка».

meta_description: одно предложение до 80 знаков, без цифр, цен и точки в конце — сайт сам допишет число моделей, цену «от» и доставку. Пример: «Толокары и каталки для малышей от года».

seo_text: HTML по формату из правил, 1 500–2 500 знаков текста:
  1) <h2> — что это за товары и зачем ребёнку, <p> 300–500 знаков;
  2) <h2> «Как выбрать …» и <ul> из 4–6 пунктов — на что смотреть родителю (возраст, размер, материал, питание, безопасность) — общие знания о товаре, не обещания про конкретные модели;
  3) <h2> про возраст: с какого возраста и почему, <p>;
  4) <h2> про покупку в Ухтышке: <p> со сроками доставки и самовывозом — только из фактов о магазине.
  Не перечисляй товары, которых нет в ДАННЫХ («автобусы, поезда» в машинках, если их нет, — брак).

seo_keywords: 5–8 запросов через запятую, как их пишут люди, с вариантами написания и городами (Алматы, Казахстан).
```

## 3. Бренд

Поля в базе (`brands`): `meta_title`, `seo_h1`, `meta_description`, `description`.
Обрати внимание: `seo_description` у бренда — НЕ описание для выдачи (из него сайт
берёт первый абзац); для выдачи — `meta_description`. Цифры бренда («8 моделей от
7 390 ₸, все в наличии») сайт вставляет в текст сам.

```
ЗАДАНИЕ: тексты для страницы бренда.

ДАННЫЕ:
- Бренд: 
- Что выпускает (по товарам в магазине): 
- Серии/линейки в магазине: 
- Примеры моделей: 
- Возраст: 
- Факты о бренде из надёжного источника (страна, год, чем известен) — если есть, с источником: 

ПОЛЯ:

meta_title: вместе с хвостом « | Ухтышка» не длиннее 60 знаков; бренд и ЧТО это за товар («Конструкторы CaDA», а не просто «CaDA»); если помещается — «купить в Алматы». Пример: «Конструкторы Sluban — купить в Алматы с доставкой | Ухтышка».

seo_h1: 2–4 слова: тип товара и бренд («Куклы Defa Lucy»). Без «купить», без города, без цен.

meta_description: 120–160 знаков, без HTML. Вперёд — что за товары и какие серии, затем доставка и самовывоз в Алматы. Чисел и цен не ставить — они меняются, сайт подставит свои.

description: HTML по формату из правил — «О бренде»:
  <h2> про бренд, <p> 400–700 знаков: что выпускает, для какого возраста, чем интересен ребёнку — факты о бренде (страна, год) только если даны в ДАННЫХ;
  <ul> из 3 пунктов: про ассортимент, кому подойдёт, про покупку в Ухтышке.
Если бренд у нас представлен 1–2 товарами — пиши о бренде, а не обещай «всю линейку».
```

## После вставки

* Товар: открыть карточку на сайте — заголовок вкладки должен содержать код модели
  целиком.
* Раздел и бренд: открыть страницу — текст стоит внизу, заголовки с иконками.
* Сайт обновится через 10 минут после последней правки (виджет внизу админки) или
  сразу по кнопке «Обновить сейчас».
