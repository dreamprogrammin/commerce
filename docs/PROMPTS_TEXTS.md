# Промпты для текстов: товары, разделы, бренды

**Где взять:** в админке, в форме товара, раздела и бренда — кнопка «Промпт для
нейросети». Она копирует в буфер обмена готовый промпт: правила магазина, блок
ДАННЫЕ с тем, что уже заполнено в форме (название, бренд, раздел, цена,
возраст, текущее описание), и задание по полям.

* Товар — кнопка в шапке «Основная информация».
* Раздел — в начале «Расширенных SEO настроек» раздела.
* Бренд — рядом с заголовком «SEO оптимизация».

**Как пользоваться.** Нажать кнопку → вставить в ChatGPT или Claude → дописать в
ДАННЫЕ факты с коробки (код модели, размеры, батарейки, комплектация) → отправить.
Ответ приходит по полям, подписанным так же, как поля формы, — вставлять по
одному. Перед сохранением проверить цифры глазами: нейросеть может ошибиться
даже с запретом выдумывать.

**Текст промптов живёт в коде** — `constants/adminPrompts.ts`, одна копия для
кнопок. Составлен 14 октября 2026 по тому, что стоит на сайте:

* факты о магазине — с `/terms` (Алматы 1–3 рабочих дня, курьер 1 000 ₸, от
  15 000 ₸ бесплатно; Казахстан 3–7 дней; самовывоз Шапагат 9:00–22:00; Kaspi;
  бонусы через 14 дней);
* запреты — те, что ловят стражи (`check-section-texts.mjs`): «широкий выбор»,
  «заказывайте прямо сейчас», «вы найдёте», выдуманные факты, эмодзи;
* формат больших текстов — HTML `h2/h3/p/ul/li` с `data-icon="fluent-emoji-flat:…"`,
  иконки — из уже используемых на сайте;
* длины — из кода: у товара часть названия до « — » не длиннее 60 знаков
  (`utils/seoTitle.ts`), заголовки разделов и брендов с « | Ухтышка» — до 60.

**Какие поля просит промпт:**

| Форма | Поля |
|---|---|
| Товар | Название товара, Описание (HTML), SEO описание (120–160) |
| Раздел | SEO заголовок (Title), H1 заголовок на странице, Ключевые слова, Описание ПОД товарами (SEO текст, HTML) |
| Бренд | Заголовок страницы (title), Заголовок на странице (H1), SEO описание (120–160 — это и есть описание в Google), Ключевые слова, Описание (HTML «О бренде») |

У раздела описание для выдачи сайт собирает сам (число моделей, цена «от»,
доставка) — в промпте его нет. Корневым разделам («Мальчикам», «Девочкам»…)
текст задан в коде (`constants/categoryStaticText.ts`).

Меняются условия доставки или правила — править `constants/adminPrompts.ts`.
