## Что осталось, по приоритету

### 1. Speed Index категории — 6.9–7.8 с, не разобран

Худшая метрика сайта (7.8 с в таблице аудита, 6.9 с в замере 17 августа).
FCP при этом 3.6 с, и он упирается в TTFB: `/catalog/boys` отдаётся с
`x-vercel-cache: MISS`, тогда как главная — `HIT` с `age` под час.

**Направление уже описано в коде** — `nuxt.config.ts`, комментарий к
`routeRules` (около строки 345): ISR для категорий пробовался и **откачен**,
потому что Vercel-пресет подменяет query-строку и ломает фильтры
(`/catalog/boys?brand=mattel` отдавал нефильтрованную страницу). Там же
записан вывод: кешировать не страницу, а **тяжёлые данные** — список из 63
категорий одинаков для всех страниц каталога и стоит около секунды на каждый
рендер. То есть смотреть в сторону Nitro `cachedFunction` вокруг выборки
категорий, а не в сторону route-правил.

### 2. Подложки товаров — 43.5 КБ на странице категории

Остаток той же темы. На `/catalog/boys` живыми остаются 34 data:URI на
43.5 КБ — это подложки товаров, и они используются честно в SSR-сетке. Но
медиана одной подложки **1.4 КБ**, тогда как типичный LQIP укладывается в
300–600 байт: запас кратный.

**Блокировано:** требует перегенерации подложек в базе, то есть записи в
прод. Только по прямому слову владельца, и сначала показать команду.

### 3. TBT главной вырос: 240 → 287 мс

Единственная метрика, которая ухудшилась. При разбросе perf 56–75 на этой же
странице утверждать регрессию нельзя, но приглядеться стоит.

### 4. Индексация: 16 необойдённых URL

273 из 309 в индексе. Гипотеза «сироты» опровергнута (граф ссылок построен).
Настоящая находка была рядом и исправлена: `/brands` был исключён из sitemap
(`82a87e8`). **Перепроверить через Search Console через несколько недель** —
помогло ли.

### 5. Проверить на проде то, что на превью не видно

`lastmod` и наличие `/brands` в боевой карте сайта: на превью `noindex`
опустошает sitemap, так что проверка возможна только на `uhti.kz`.
Это **не** повод предлагать выкатку — просто пометка, что проверка отложена.

### 6. Мёртвый компонент

`components/category/CategoryDescription.vue` не подключён ни на одной
странице (совпадения в поиске — одноимённые функции
`generateCategoryDescription` в `pages/catalog/[...slug].vue`). Чистка —
отдельной `refactor/*`, не попутно.

### 7. OG-картинки остальных шаблонов

`components/OgImage/Home.vue`, `Product.vue`, `ProductSimple.vue` всё ещё на
Tailwind-классах и с эмодзи. Satori этого не понимает: утилиты Tailwind 4 он

переписан — `components/OgImage/Catalog.vue`: инлайновые стили, одна колонка,
без эмодзи.

```bash
# Локальный Supabase: kong-контейнер часто не поднят, и тогда всё падает
# в «fetch failed», а sitemap отдаёт 8 адресов вместо 288. Проверять так:
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:54321/rest/v1/

```

Прочие ловушки:

- `.env` смотрит в **локальную** базу (`127.0.0.1:54321`), а превью
  `dev.uhti.kz` — в **боевую**. Не путать при сверке цифр.
- **PSI кэширует результаты.** Между прогонами пауза 90 секунд, иначе
  «медиана трёх прогонов» окажется одним и тем же значением трижды.
- **Локальный Lighthouse в WSL не поднимается** — `NO_FCP`, затем
  `ERR_ABORTED`. И насыпает в корень репозитория каталоги с виндовыми
  путями (`C:\Users\...\lighthouse.NNNNN`) — удалять.
- `pkill -f '<шаблон>'` совпадает с собственной командной строкой и убивает
  свою же оболочку (код 144). Писать шаблон так: `'inde[x].mjs'`.
- `.claude/settings.local.json` в этом репозитории **отслеживается git**,
  несмотря на имя. Держим его намеренно незакоммиченным: там
  WSL-специфичный `LD_LIBRARY_PATH`.
- `.env.dev` и `.env.example` **отслеживаются git** — учётные данные туда
  не писать никогда. Гитигнорятся только `.env` и `.env.local`.

## Скрипт, которым мерился вес документа

Кладётся в корень репозитория, после работы удаляется.

```js
import { brotliCompressSync } from "node:zlib";

for (const url of process.argv.slice(2)) {
  const html = await (
    await fetch(url, {
      headers: {
        "user-agent": "Mozilla/5.0 (Linux; Android 11) Chrome/140 Mobile",
      },
    })
  ).text();
  const br = (s) => brotliCompressSync(Buffer.from(s)).length;
  const stripped = html.replace(/"data:image[^"]*"/g, '""');
  const uris = [...html.matchAll(/"(data:image[^"]*)"/g)].map((m) => m[1]);
  console.log(`\n${url}`);
  console.log(
    `  brotli ${(br(html) / 1024).toFixed(1)} КБ → без data:URI ${(br(stripped) / 1024).toFixed(1)} КБ`,
  );
  console.log(
    `  data:URI: ${uris.length} шт, сырьём ${(uris.reduce((s, u) => s + u.length, 0) / 1024).toFixed(1)} КБ`,
  );
}
```

Заголовок `x-vercel-cache` смотреть тем же `fetch` — им и обнаружился `MISS`
на категориях против `HIT` на главной.
